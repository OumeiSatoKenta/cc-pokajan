## A. 差し戻しが必要（実装すると権利問題か、嘘の UI になる）

### A-1. 実在作品の名前が全面に入っている

グループ名（`マクロス7` / `マクロスPlus` / `マクロスΔ` / `マクロスF`）と
キャラクター名（`バサラ` `ミレーヌ` `レイ` `ビビーダ` `ミュン` `ガルド` `シャロン` `イサム`
`三雲` `カナメ` `マキナ` `レイナ` `フレイア` `アルト` `ランカ` `シェリル`）が

ダミーデータのつもりでも、**モック画像自体が成果物として残る**ので差し替えが必要。

**同梱ロスター（オリジナル）を使うこと。**

| ---- | ---- |
| ステラ組 | ノヴァ / ルクス / ヴェガ |

> **字数の設計にも影響する。** 同梱名はカタカナ2〜4文字だが、
> **ユーザーは自分のチーム名に差し替えて遊ぶ**のがこのゲームの前提なので、

### A-2. 存在しない機能の UI が3つ入っている

| モックの表示 | 実際 |
| ---- | ---- |
| **供託 0本** | 供託・リーチ棒の概念が**無い**。点棒を場に出す仕組みが存在しない |

麻雀の一般的な卓 UI から連想して足したのだと思うが、実装しようがないうえ、

空いた場所には、実際にある情報を置ける:

- **連続和了の回数**（和了しても局が終わらず、最大8回続く。今何回目かは意味がある）
- **BET 額**（この対局に賭けた額。順位倍率で精算される）

### A-3. 待ちのカードを緑にしていて、カードの色情報が壊れている

手札の「シェリル」2枚が**緑**になっている。緑は3色（桃 / 青 / 橙）のどれでもない。

**このゲームではカードの色が役の判定に直結する。**
役の構成カードが全て同色だと点数が跳ね上がる（3カード 120点 → 同色 840点）。
面の色を強調表示で上書きすると、**そのカードで同色役が狙えるかどうかが読めなくなる**。

実際このモックでは、待ち一覧が「シェリル（桃）残3 / シェリル（青）残2 / シェリル（橙）残2」と
3色すべてを挙げているのに、手札の2枚が何色なのかが分からない。

現状の実装は**面の色を残したまま、外側だけで強調**している:

```css
.card--waiting {
  border-color: #ffd34d;
  box-shadow: 0 0 0 2px #ffd34d, 0 0 12px rgb(255 211 77 / 0.5);
}
```

枠・グロー・持ち上げ・浮かせるなど、**面の色を殺さない方法**にしてほしい。

> 案A の真鍮（`#d9a441`）とこの黄色（`#ffd34d`）は近いので、
> 卓を金基調にするなら強調側を白熱寄り（`#ffe58a` ＋外側グロー）にして
> **輝度で差をつける**必要がある。ここは実装時に必ず目視する。

## B. 重要な欠落

### B-1. 河（捨て札の置き場）が無い

現在の盤面は**4人全員が伏せ手札と河を持つ**。モックには河が1つも無い。

河はこのゲームで3つの役割を持つ:

1. **ロンの対象**。他家が捨てたカードで役が成立すると割り込める
2. **残り枚数の根拠**。「見えているカード = 自分の手札 + 全員の河 + 成立済みの役」
3. 何が切られたかの読み

捨てたカードがどこへ行くのかが分からないと、ゲームとして成立しない。
**4人分の河の置き場**を設計に入れてほしい（現状は各席の手札の内側）。

### B-2. 「ツモ」「ロン」が常時表示になっている

実際は**役が成立しているときだけ**出る。しかも同時には出ない:

| 局面 | 出るボタン |
| ---- | ---- |
| 自分の手番・引いた直後に役がある | 「ツモ（役名 点数）」＋「見送る」 |
| 他家の捨て札で役が成立 | 「ロン（役名 点数）」＋「見送る」 |
| それ以外 | **何も出ない**（打牌の案内だけ） |

常に2つ並んでいると「いつでも押せる」と誤解される。
**何も出ていない状態**が実際には一番長いので、その状態の設計がほしい。

また、ボタンには**役名と点数**が入る（「4人組 390点」のように）。
文字数が変わるので、固定幅にしないでほしい。

### B-3. 持ち時間が1種類しかない

「残り12秒」とあるが、実際は**3種類**あり、意味が違う。

| 種別 | いつ | 注意 |
| ---- | ---- | ---- |
| 打牌 | 自分が捨てる番 | 切れるとツモ切りされる |
| 宣言 | 自分に和了の権利がある | 切れると見送りになる |
| **割り込み** | **他家の手番中** | 他家の捨て札にロンできるとき |

**割り込みは自分の手番でないときに走る**のが要点で、
「今どの判断を待たれているのか」が分からないと押し間違える。
3種を見分けられるようにしてほしい（色・ラベル・位置のいずれか）。

なお持ち時間は**使い切ったときだけ**短くなる仕様（20秒 → 下限5秒）。
数字が対局中に変わるので、桁が変わっても崩れないこと。

## C. 次稿までに決めてほしい状態

デザインは「良いときの1枚」ではなく、**壊れやすい状態が描けているか**で判断したい。

| # | 状態 | なぜ必要か |
| - | ---- | ---- |
| 1 | **残0 の待ち** | 役はできるがその札はもう場に無い。ここを淡く落とすのが残り枚数機能の中心 |
| 2 | **待ちが多いとき** | 理論上60件出る。今は「上位6件 + 他N件」で打ち切っている。チップ1行だと3つで一杯 |
| 3 | **アバター未設定** | 画像を入れずに遊べるのが要件。席名の頭文字にフォールバックする |
| 4 | **カードに写真が入ったとき** | ユーザーが自分の写真に差し替えるのがこのゲームの目玉。名前と記号が写真に負けないこと |
| 5 | **点数が0 / 4桁** | 0になると破産で対局終了。点数は大きく動く |
| 6 | **連続和了** | 和了しても局が終わらず最大8回続く。演出が8回続いても邪魔にならないこと |
| 7 | **ライトテーマ** | `prefers-color-scheme` で切り替わる。モックはダークのみ |
| 8 | **375px** | モックは 1574px 幅。縦積みの規則が要る |
| 9 | **ボーナス** | 1人だけ（`bonusMemberCount: 1`）。役に含まれると1枚 +90点 |
