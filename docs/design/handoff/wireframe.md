# ワイヤーフレーム：領域・件数・状態

「良いときの1枚」ではなく**壊れやすい状態**を含めて設計してもらうための資料。
文字数・件数・空の状態がここに書いてある。

---

## 0. 画面の全体像

```
タイトル ──▶ BET ──▶ 対局 ──▶ 精算 ──▶ タイトル
   │                    │
   ├─ ロスター設定       ├─ 和了演出（対局中に最大8回）
   ├─ プレイヤー設定     └─ 終局オーバーレイ
   └─ ルール設定
```

優先度は **対局 > 和了演出 > BET・精算 > タイトル > 各設定**。
対局画面だけで遊んでいる時間の 95% を占める。

---

## 1. 対局画面（デスクトップ）

現在の実装は **3×3 のグリッド**。上家=左 / 対面=上 / 下家=右 / 自分=下、中央が場。
**席の位置は人間の席からの相対**で決まるので、この配置は動かさないでほしい。

```
┌──────────────────────────────────────────────────────────────┐
│ ヘッダー  ポカジャン          ※第1稿の「東1局/親/ONLINE」は無い │
│                              置けるのは 連続和了 0/8 ・ BET 1,000 │
├──────────────────────────────────────────────────────────────┤
│              ┌──────── 対面 ────────┐                         │
│              │ 名前 750  役0         │                         │
│              │ 伏せ札 ×7             │                         │
│              │ 河 ×4      ← 必須      │                         │
│              └───────────────────────┘                         │
│ ┌─── 上家 ───┐  ┌──────── 場（中央）────────┐ ┌─── 下家 ───┐ │
│ │ 1,140 役2  │  │ 山札 36枚                  │ │ 1,060 役2  │ │
│ │ 伏せ札 ×7  │  │ ボーナス [ヴェガ] ×1        │ │ 伏せ札 ×7  │ │
│ │ 河 ×4      │  │ グループ進捗 ×4            │ │ 河 ×4      │ │
│ │            │  │  マリン組  1/4             │ │            │ │
│ │            │  │  シルヴァ組 2/4            │ │            │ │
│ │            │  │  テラ組    3/5             │ │            │ │
│ │            │  │  ステラ組  2/3             │ │            │ │
│ └────────────┘  └────────────────────────────┘ └────────────┘ │
│              ┌──────── あなた ───────┐                         │
│              │ 河 ×4                 │                         │
│              └───────────────────────┘                         │
├──────────────────────────────────────────────────────────────┤
│ あなた 1,050点          待ち ×6（上位のみ＋「他N件」）  案内文    │
│ 手札 ×8（引いた1枚は離す）                    操作エリア          │
│                                               残り時間バー        │
└──────────────────────────────────────────────────────────────┘
```

### 各領域の中身と件数

| 領域 | 中身 | 件数・幅の制約 |
| ---- | ---- | ---- |
| 他家の席 ×3 | 席名・点数・成立役数・**伏せ札**・**河** | 伏せ札は 7〜8枚。河は 0〜30枚程度で**上限なし** |
| 場（中央） | 山札の残り・ボーナス1人・グループ進捗4つ | グループは 3〜5人。分母が変わる |
| 自分の河 | 捨てたカード | 0〜30枚程度 |
| 自分の情報 | 「あなた」＋点数＋（アバター） | 点数は 0〜4桁 |
| 待ち | メンバー・色・残り枚数・役・点数 | **0〜60件**。0件なら**領域ごと出さない** |
| 手札 | カード 7〜8枚 | **8枚が必ず1行**。引いた1枚は離す |
| 操作 | 状況により変わる（下記） | **何も出ない状態が最も長い** |
| 残り時間 | 打牌 / 宣言 / **割り込み** の3種 | 20秒 →（使い切ると減る）→ 下限5秒 |

### 河は必須（第1稿で抜けていた）

河は3つの役割を持つので、省略できない。

1. **ロンの対象**。他家が捨てたカードで役が成立すると割り込める
2. **残り枚数の根拠**。「見えている＝自分の手札 + 全員の河 + 成立済みの役」
3. 何が切られたかの読み

**直前に捨てられた1枚**が分かるとなお良い（ロンの判断対象）。

## 2. 操作エリアの状態（第1稿は「ツモ」「ロン」が常時表示だった）

排他的に切り替わる。**同時には出ない。**

```
[A] 相手の手番（最も長い）
    ┌────────────────────────┐
    │ 相手の手番です          │   ボタン無し。時間バーも無い
    └────────────────────────┘

[B] 自分が捨てる番
    ┌────────────────────────┐
    │ 捨てるカードを選んでください │  手札が押せる状態になる
    │ ▓▓▓▓▓▓▓░░░ 残り12秒      │  打牌のタイマー
    └────────────────────────┘

[C] 自分の手札で役が成立（ツモ）
    ┌────────────────────────┐
    │ 役が成立しています        │
    │ [ 3人組 630点 ] [ 見送る ]│  役が複数なら**ボタンも複数**
    │ ▓▓▓▓░░░░░░ 残り8秒       │
    └────────────────────────┘

[D] 他家の捨て札に割り込める（ロン）※他家の手番中に出る
    ┌────────────────────────┐
    │ 割り込めます             │
    │ [ 4人組 390点 ] [ 見送る ]│
    │ ▓▓░░░░░░░░ 残り4秒       │  ← 割り込みのタイマー。他家の手番なのに走る
    └────────────────────────┘
```

- **ボタンの文字は「役名 + 点数」で可変長**（`3カード 120点` 〜 `5人組 1800点`）
- **役が複数成立していればボタンも複数**並ぶ
- [D] は**自分の手番でないときに出る**。[B] と見分けがつかないと押し間違える

## 3. 375px（縦積み）

現在は3×3グリッドを1列に積んでいる。**横スクロールは出さない。**

```
┌──────────────────┐
│ 対面（伏せ札・河）│
├──────────────────┤
│ 上家             │
├──────────────────┤
│ 下家             │
├──────────────────┤
│ 場（山札/ボーナス │
│ /グループ進捗）   │
├──────────────────┤
│ 待ち（役名の列は  │
│ 落として3列に）   │
├──────────────────┤
│ 自分の河         │
├──────────────────┤
│ 手札 ×8（縮小）   │
├──────────────────┤
│ 操作・時間バー    │
└──────────────────┘
```

- 手札8枚は**縮小してでも1行**（折り返すと手札の把握ができない）
- 待ち一覧は幅が足りないので**役名の列を落とす**（残り枚数と点数は残す）
- 残り枚数のツールチップは**手札全体を基準に絶対配置**する。
  カード単位に置くと端の札で画面外へ出る

## 4. 和了演出（2段・自動で閉じる）

```
段1: カットイン（1.2秒）      段2: 点数獲得結果（2.5秒）     → 自動で閉じる
┌──────────────────┐        ┌──────────────────────┐
│   ◯ アバター     │        │ 上家 / 3人組 同色 ロン │
│   上家           │   →    │ [カード][カード][カード]│
│   3人組 同色 ロン │        │      + 630点          │
└──────────────────┘        │ 順位表（順位が動く）    │
                            └──────────────────────┘
```

- クリックで1段進む / Escape でいつでも閉じる / **確認ボタンは無い**
- **同色役のときだけ「大物手」バージョン**（現状は金の輪郭・放射・バッジ）
- **最大8回連続で再生されうる**。8回見ても邪魔にならないこと
- 「視覚効果を減らす」設定では**動きは消えるが滞留時間は変わらない**

> 第1稿への指摘（`review-01.md` A-3）と同じで、段2 に並ぶ**役の構成カードは
> 面の色が読めること**。同色かどうかが絵で分かるのがこの段の価値。

現状のカットインは中央の白いパネルで、**モーダルにしか見えない**のが最大の不満。
画面全体を使う構造（斜めの帯・卓そのものを動かすなど）を提案してほしい。

## 7. 触ってはいけない構造

実装済みで、変えるとロジック側の修正が必要になるもの。

- **席の配置**（上家=左 / 対面=上 / 下家=右 / 自分=下）。相対位置で計算している
- **カードの3色**（ピンク/青/オレンジ）。役の判定に直結
- **待ちの強調は面の色を殺さない**（枠・グローで）
- **伏せ札に中身を出さない**
- クラス名（`docs/design/brief.md` の「3-4. クラス名の目録」）
