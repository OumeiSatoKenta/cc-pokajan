モックに使う名前・数値・文言は**すべてここから取ること**。

## 1. 同梱ロスター（オリジナル・6グループ22人）

1局には**この6つから4グループが選ばれて登場**する。ユーザーは設定画面から
名前も人数も画像も差し替えられるので、**この名前に最適化しすぎない**こと。

| グループ | 記号 | 人数 | メンバー |
| ---- | :--: | :--: | ---- |
| ステラ組 | ス | 3 | ノヴァ / ルクス / ヴェガ |
| ソレイユ組 | ソ | 3 | ソル / アウロラ / ヘリオ |
| ゼファー組 | ゼ | 3 | ゼフィル / ノトス / ボレアス |
| マリン組 | マ | 4 | ネレイス / コーラル / ティード / アビス |
| シルヴァ組 | シ | 4 | フローラ / ブラン / ヴェルデ / モス |
| テラ組 | テ | 5 | ガイア / ペトラ / ルーン / オニキス / アガット |

- **記号**はカードの角に出す（トランプのスートに相当）。既定はグループ名の1文字目
- グループ名が似ている場合（「ステラ組」「ソレイユ組」）に備え、記号は**上書き設定できる**
- **メンバー名の長さは可変**。ユーザーが「アレクサンドラ」のような長い名前を入れうる

## 2. 画面に出る文言（すべて実装済みの固定文字列）

### 色

`ピンク` / `青` / `オレンジ`（内部値は `pink` / `blue` / `orange`）

### 役

| 表示 | 条件 | 基本点 | 同色 |
| ---- | ---- | ----: | ----: |
| `3カード` | 同一メンバー3枚 | 120 | 840 |
| `3人組` | 3人グループ全員を1枚ずつ | 180 | 540 |
| `4人組` | 4人グループ全員 | 300 | 840 |
| `5人組` | 5人グループ全員 | 480 | 1800 |

**ボーナスメンバーが役に含まれると1枚につき +90点。** ボーナスは**1人だけ**。

> 同色で最大7倍になるため、**カードの色は装飾ではなく情報**。
> 表示上の実際の点数は「基本点/同色点 + 90×ボーナス枚数」なので、
> `630`（3人組同色 540 + 90）のような**表に無い数字**が普通に出る。

### 席の呼び名

`あなた` / `下家` / `対面` / `上家`（自分から見た相対位置。時計回り）

### 操作の案内（画面下に1行で出る）

| 状況 | 文言 |
| ---- | ---- |
| 自分が捨てる番 | `捨てるカードを選んでください` |
| 他家の捨て札に割り込める | `割り込めます` |
| 自分の手札で役が成立している | `役が成立しています` |
| 対局が終わった | `対局終了` |
| **上記以外（最も長い時間これ）** | `相手の手番です` |

### 終局の理由

`山切れ` / `破産`

## 3. 数値の範囲（レイアウトが壊れる条件）

| 項目 | 範囲 | 注意 |
| ---- | ---- | ---- |
| プレイヤー数 | 4（人間1 + CPU3） | 設定で変更可 |
| 手札 | **7枚**、引いた直後だけ**8枚** | 8枚が1行に収まること。引いた1枚は離して見せる |
| 山札 | 100 → 0 | 0 で終局。**減る一方** |
| 点数 | 開始 1,000 / 下限 **0**（0で破産・終局） | 4桁までは普通に出る。カンマ区切り |
| 河（1人） | 0 〜 30枚程度 | **上限が決まっていない**。溢れたときの規則が要る |
| 待ち | 0 〜 **60件**（理論上限） | 今は「上位6件 + 他N件」で打ち切っている |
| 残り枚数 | 0 〜 3 | **0 は「その待ちはもう上がれない」の意味** |
| 連続和了 | 0 〜 **8回** | 和了しても局が終わらない。演出が8連続しうる |
| 登場グループ | 4つ（3〜5人） | 進捗は `1/4` `3/5` のように分母が変わる |
| 持ち時間 | 20秒 → 使い切るたびに減り、下限 **5秒** | 対局中に桁は変わらないが値は変わる |
| BET | 1,000 / 2,000 | 順位倍率 1位 2.5 / 2位 1.5 / 3位・4位 1.0 |
| 所持コイン | 初期 10,000 | 5桁 |

## 5. このゲームに**無い**もの（第1稿で混入していた）

- **供託・リーチ棒** … 点棒を場に出す仕組みが無い
- **場・局・親（東1局、親 対面 など）** … 1局を山切れか破産まで打ち切るだけ
- **オンライン対戦** … 完全にクライアントサイド。相手は CPU3人
- **ドラ・裏ドラ** … ボーナスメンバー（1人・+90点）が近いが別物
- **鳴き（ポン・チー）** … 割り込みは「ロン（他家の捨て札での和了）」だけ
- **点棒のやり取りの表示** … 精算は順位倍率でまとめて行う
