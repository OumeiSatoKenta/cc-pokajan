## メインの依頼（対局画面 第2稿）

```
カードゲームの対局画面をデザインしてください。第1稿の方向（木枠 + 羅紗の卓、
中央への情報集約、グループ進捗の「1/4」表記と所持メンバーの金ハイライト）は
そのまま活かしてください。

## このゲーム
麻雀/ドンジャラを簡略化した4人対戦（人間1 + CPU3）。
手札7枚、「山から1枚引く → 1枚捨てる」の繰り返し。
役は「同一キャラ3枚（3カード）」と「グループ全員を1枚ずつ（3〜5人組）」の2種類だけ。
カードはピンク/青/オレンジの3色で、役が全て同色だと点数が最大7倍になる。
和了しても局が終わらず、カードを補充して最大8回続けて和了できる。
BET → 対局 → 順位に応じた精算、というカジノのループで回る。
キャラクターはユーザーが自分の写真とチーム名に差し替えて、身内で遊ぶ想定。

## 第1稿から必ず直すこと
1. グループ名・キャラクター名が実在作品のものになっていました。
   添付の data.md にあるオリジナルの同梱ロスターを使ってください。
   ただしユーザーが任意の名前に差し替える前提なので、
   長い名前（例:「アレクサンドラ」）が来たときの折り返し・省略の規則も決めてください。

2. 「供託」「東1局・親」「ONLINE」は、このゲームに存在しない機能でした。
   削除してください。data.md の「このゲームに無いもの」を確認してください。
   空いた場所に置けるのは「連続和了の回数（0〜8）」か「BET額」です。

3. 待ちのカードを緑にすると、カードの色（ピンク/青/オレンジ）が読めなくなります。
   このゲームでは色が役の判定に直結する情報なので（同色で最大7倍）、
   面の色を残したまま、枠・グロー・浮き上がりなど外側だけで強調してください。

4. 河（捨て札の置き場）が4人分とも抜けていました。
   河はロンの対象であり、残り枚数の計算根拠でもあるため省略できません。

5. 「ツモ」「ロン」が常時表示でしたが、実際は役が成立したときだけ、
   しかも排他的に出ます。何も出ていない状態が最も長いので、その状態も設計してください。
   ボタンの文字は「役名 + 点数」で可変長、複数並ぶこともあります。

## 使うデータ
添付の state-sample.json は実際のゲームエンジンが生成した局面です。
名前・点数・枚数・待ちの内容は**これをそのまま使い、値を捏造しないでください**。

## 制約
- 素の CSS で実装します。Tailwind も CSS-in-JS も使っていません
- 装飾は CSS（グラデーション・影・擬似要素・インライン SVG）で表現できる範囲に。
  画像アセットを前提にしないでください
- 外部フォントは読み込めません（オフラインで完結させるため）
- ライトテーマとダークテーマの両方が必要です
- 375px 幅で横スクロールを出さないこと
- 席の配置（上家=左 / 対面=上 / 下家=右 / 自分=下）は変更できません
- 伏せ札に中身が漏れる表現を足さないでください

## 出してほしいもの
添付 wireframe.md の「6. 描いてほしい状態」の一覧を埋める形で、
1枚絵ではなく状態ごとに出してください。特に次の4つは必須です。

- 自分が捨てる番（state-sample.json の局面そのまま）
- 相手の手番（操作エリアが空・時間バー無し）※最も長い状態
- 割り込みできる（他家の手番なのにボタンとタイマーが出る）
- 残0 の待ちが混ざっている

あわせて、以下を文章で説明してください。
- 河の置き場と、枚数が増えたとき（1人30枚程度まで）の扱い
- 待ちが 60件出うることへの対処（今は上位6件＋「他N件」）
- カードに写真が入ったとき、名前とグループ記号が写真に負けない方法
```

## 追加の依頼（和了演出・カットイン）

対局画面が固まってから出す。

```
同じゲームの「和了（あがり）演出」を設計してください。仕様書と絵コンテを出してください。

## 現状
- 2段構成: カットイン(1.2秒) → 点数獲得結果(2.5秒) → 自動で閉じる
- カットイン: 円形アバター(未設定なら席名の頭文字)、席名、役名、ツモ/ロン
- 結果: 役の構成カード3〜5枚、獲得点、4人の順位表(順位が入れ替わると行が動く)
- 同色役のときだけ「大物手」バージョン
- クリックで1段進む / Escape で閉じる / 確認ボタンは無い

## 最大の不満
中央に角丸パネルが出るだけで、**モーダルにしか見えない**。
画面全体を使う構造（斜めに走る帯、卓そのものを動かす、など）を3案以上提案してください。

## 制約
- framer-motion 13 と CSS のみ。新しいライブラリは足さない
- 画像アセットを使わない
- 375px で成立する
- prefers-reduced-motion: reduce のとき「動き」は消えるが「滞留時間」は変えない
  （動きを減らす設定であって、読む時間を減らす設定ではない）
- **最大8回連続で再生される**。8回見ても邪魔にならないこと
- 段の長さは変更提案してよいが、合計4秒を大きく超えないこと
- 結果段に並ぶ役の構成カードは**面の色が読めること**（同色かどうかが絵で分かるのが価値）

## 出してほしいもの
1. 通常役と大物手それぞれの、時間軸つき絵コンテ（0.0s / 0.2s / ... と刻む）
2. 各要素の easing・duration・delay の具体値
3. 「モーダルに見えない」ための構造案を3つ以上
4. 大物手を「別格」に見せる差分を5つ
5. reduced-motion のときの代替表現
6. 費用対効果が高い順の優先度
```
