# ポカジャン アートディレクション 3案（依頼A の成果物）

依頼書は [brief.md](brief.md)。この文書は**方向を1つ選ぶため**のもので、
選んだあとに依頼B（カットインのモーション）と依頼C（CSS実装）へ進む。

3案とも**実際の画面に当てて撮影してある**（モックではない）。
テーマ CSS は [proposals/](proposals/) にあり、**アプリからは import していない**。

> 撮影方法: Playwright で対局を進め、`page.addStyleTag({ path })` でテーマを流し込んで

## 案A「深夜の雀荘」

**一行**: 一点の灯りに照らされた、深夜の卓。

羅紗（ラシャ）の深緑、飴色の真鍮、沈んだ木。画面の上から灯りが1つだけ落ち、
卓の中心が明るく、端に向かって暗く沈む。見出しは**明朝**にして、
昭和の雀荘の看板の字面を借りる。派手さではなく「腰を据えて長く打つ場所」の空気を作る。

カード3色は**古い牌のような象牙寄り**に落とす（`#e0a9b3` / `#a8c2d4` / `#ddb887`）。

**質感**: 角丸 0.6rem 前後。パネルは上端に白 5% のハイライト、下に強い影。
罫線は真鍮を 22% で薄く。卓面は 92° の細いストライプで布目を作る。

本文＝既存のゴシックのまま。**外部フォントの追加なし。**

**和了の瞬間**: 上から灯りが強くなり、卓が沈む。真鍮の輪がアバターを囲む。
大物手では真鍮が焼けるように白熱し、金の文字が浮く。

**コスト**: 低〜中 ／ **弱点**: 地味。静かすぎて「カジノの高揚」は出ない。

藍から紫へ沈む闇に、シアンとマゼンタの管が灯る。床は透視グリッド。
数字は電光掲示板のように等幅で光る。見出しはゴシックを太く、字間を大きく開けて看板にする。

カード3色は**彩度を上げて発光させる**（`#ff5cb4` / `#35c6ee` / `#ff9a2e`）。

**質感**: パネルの下端にシアン→マゼンタの管が1本走る（`::before`）。

**タイポ**: 見出し＝ゴシック 800、字間 0.22〜0.42em。数字は `tabular-nums` にシアンの発光。

ピンクのカードとマゼンタの強調、青のカードとシアンの強調が同じ画面で競合し、
「色＝役の情報」という機能を弱める。目も疲れる。

## 推薦

### 案A を基調にし、**カットインの構造だけ案B から借りる**

理由は3つ。

**1. Aのパレットは機能を助ける。** このゲームはカードの色（ピンク/青/オレンジ）が
役の判定に直結する。**深緑と真鍮はその3色のどれとも競合しない**ので、
卓を濃く塗っても手札の色は濁らない。Bのマゼンタ/シアンは
ピンクのカード・青のカードと同じ色域を取り合い、
「装飾なのか情報なのか」が一目で分からなくなる。これは好みではなく機能の問題。

**2. Aだけがライトとダークの両方で同じゲームに見える。**
Cはダークにすると主題（紙と箔）が消えて別物になる。Bのライトは
「昼の筐体」という無理のある設定になっている。

**3. Aの唯一の弱点は「和了が地味」で、それはBの構造で直せる。**
Bの強さはパレットではなく**画面全体に斜めの帯を走らせた構造**にある
（`.win-overlay` の背景で、パネルの外側が動く）。
`t-a-cutin.png` と `t-b-cutin.png` を並べると、Bだけがモーダルに見えない。
この構造は色に依存しないので、**真鍮の帯**として案Aに移植できる。

### つまり最終形

- 卓・アウトゲーム・設定 → **案A**（深緑の羅紗、真鍮、明朝の見出し、上からの灯り）
- 和了演出 → **案Aの色 × 案Bの構造**（画面全体を横切る真鍮の帯、大物手で光条）

### 先に潰しておく懸念

| 懸念 | 対処 |
| ---- | ---- |
| 真鍮（`#d9a441`）と**待ちの黄色枠**が近く、強調が埋もれる | 待ちの枠を白熱寄り（`#ffe58a`＋外側グロー）にして、真鍮の面と輝度で差をつける。実装時に必ず目視する |
| ライト（昼の卓）が案Cと似た印象になる | ライトでも卓面は緑（`#3f6b52`）を保ち、紙色にしない |
| 明朝は Windows で `Yu Mincho` になり印象が変わる | 見出しだけに限定し、本文はゴシックのまま。字面が変わっても崩れない |
