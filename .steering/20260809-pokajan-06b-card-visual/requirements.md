# Step 6b: カードの見た目（画像の非トリミング + グループ記号） — 要求内容

> **このステアリングは後追いで作成した。**
> 実装は 2026-08-09 に会話でのフィードバックを受けて先に完了しており、
> 本書は作業記録を他ステップと同じ形で残すために書き起こしたもの。
> 内容は実装済みのコードとテストに基づく（計画時点の推測は含まない）。

## 背景

Step 6 でロスターと画像を差し替えられるようになった直後、実際に画像を入れて
遊んだ結果として2件の指摘が出た。

いずれも Step 4b と同じく **「テストは全部通っているのに、遊ぶと困る」** 種類のもので、
自動検証では検出できていなかった。

## 要求

### R1: アップロードした画像を切り取らない

**ユーザーストーリー**
利用者として、選んだ写真がそのまま出てほしい。勝手に切り取られたくない。

**現状の問題**
Step 6 の実装は `centerSquareCrop` で**中央を正方形に切り出して**いた。
集合写真やロゴのように横長・縦長の画像を入れると、端が消えて別物になる。

**受け入れ条件**

- [x] 保存時に画像を切り取らない（縦横比を保ったまま長辺を 256px に収める）
- [x] 元画像が 256px より小さい場合は拡大しない
- [x] **表示時にも切り取らない**（`object-fit: contain`）
- [x] カードとロスター設定のサムネイルの両方に適用される
- [x] 極端な縦横比（10000×1 など）でも描画できる寸法を返す

**優先度**: P0

---

### R2: グループの記号をカードの角に表示する

**ユーザーストーリー**
プレイヤーとして、手札のカードがどのグループのものか一目で分かるようにしたい。
トランプのスートのように、左上と右下に記号が出てほしい。

**現状の問題**
カードにはメンバー名しか出ておらず、そのメンバーがどのグループかは
場の情報（`BoardInfo`）と照合しないと分からない。
画像を設定すると名前が読みづらくなり、判別はさらに難しくなる。

**受け入れ条件**

- [x] カードの**左上と右下**にグループの記号が出る（右下は 180 度回転）
- [x] 記号はグループごとに設定できる
- [x] 未設定なら**グループ名の1文字目**を使う
- [x] 記号を空にすると名前からの導出に戻る
- [x] 記号がメンバー名と重ならない
- [x] 幅 375px でも記号と名前が両立する
- [x] 書き出しファイルに記号が含まれ、記号の無い旧ファイルも読める

**優先度**: P0

---

### R3: 画像がカードに正しく描画される（実装時に判明）

**背景**: R1 の対応中に、**`.card__image` の CSS がそもそも存在しない**ことが分かった。
Step 6 では画像表示を実装したつもりだったが、対局画面での見た目を一度も確認しておらず、
E2E もロスター設定のサムネイルしか見ていなかった。実際には画像が原寸で描画され、
カードから溢れる状態だったと考えられる。

**受け入れ条件**

- [x] カード内に画像が収まる
- [x] 画像の上でもメンバー名が読める
- [x] 画像の読み込みに失敗したら名前表示へ戻る（既存要件の維持）

**優先度**: P0

---

## スコープ外

| 項目                       | 理由                                     |
| -------------------------- | ---------------------------------------- |
| 画像のトリミング UI        | 「切り取らない」が要求。切る手段は不要   |
| 記号の色・字体の個別設定   | 要求されていない                         |
| 他家の手札への記号表示     | 伏せ札なのでカード自体を描画していない   |

## 非機能要件

- 既存の 612 ユニットテスト / 47 E2E を壊さない
- エンジン層の変更は `Group.symbol` の型追加のみ（ロジックは変えない）
- 検証ゲート: `npm run lint && npm run typecheck && npm test && npm run build && npm run format:check`
