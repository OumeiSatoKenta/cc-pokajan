# 要求: 絵札選択UI・ツモ（Step 2 / UI）

## 背景

参照: [docs/ideas/pokajan-yaku-card-selection-plan.md](../../docs/ideas/pokajan-yaku-card-selection-plan.md)（全3ステップ・本 Step 2）
前提: **Step 1（エンジン）完了**。`candidateFromSelection`（`src/engine/yakuSelection.ts`）が選択 uid 集合から
役を再導出し、DECLARE/CLAIM の検証がそれを使う。UI はまだ選択操作を提供していない。

現状、自分の番（`selfDeclare`）では `ActionBar` の候補ボタンを押すと**即座にツモ確定**し、
プレイヤーは「どの色の絵札を何枚使い、何を手札に残すか」を選べない。本 Step は**ツモ経路**に
カードタップによる役構成＋ライブプレビュー＋確定を導入する（ロンは Step 3）。

## スコープ（今回やること）

1. **手札タップで役を構成**（`selfDeclare`・人間が宣言権者のとき）: `Hand`/`CardView` に選択モードを追加。
   タップで選択トグル、`.card--selected` を付与（面の色は塗り替えない・リング＋持ち上げで示す）。
2. **ライブプレビュー**: 選択が作る役（役名＋同色＋点数）を即時表示。未成立時は案内文。
3. **確定（ツモ）**: 有効な役のときだけ活性化する緑ボタン。押下で `loop.declare(composed)`。
4. **おまかせプレフィル**: `ActionBar` の既存候補ボタンを、押下で選択欄へ**プレフィル**（即確定しない・上書き可）に変更。
5. **discard フェーズのタップは従来どおり捨て札**（座標・375px・横向き E2E を壊さない）。

## スコープ外（今回やらないこと）

- **ロン（`claimWindow`）の選択 UI** — Step 3。`claimWindow` の候補ボタンは従来どおり即時（変更しない）。
- エンジンの変更（Step 1 で完了。`candidateFromSelection` をそのまま使う）。
- 永続化（選択は一局中の一時 UI 状態）。

## 受け入れ基準

### 機能

- [x] `selfDeclare`（人間が宣言権者）で手札カードをタップすると選択がトグルし、`.card--selected` が付く。
- [x] 選択が有効な役を作ると、プレビューに役名（＋同色）＋点数が出て、緑のツモボタンが活性化する。
- [x] 選択が役にならない／空のときはツモボタンが不活性で、案内文が出る。
- [x] ツモボタン押下で `loop.declare(composed)` が呼ばれ、和了する。**選んだ札そのものが消費される**
      （非正準の合法選択でツモできる＝Step 1 の再導出検証を通る）。
- [x] おまかせ候補ボタンを押すと選択欄がプレフィルされ、そこから手動で上書きできる（即確定しない）。
- [x] 色の取り方で役・点数がライブに変わる（おまかせ候補ごとにプレビューの点数が切り替わる E2E で担保）。

### 非破壊（既存の維持）

- [x] `discard` フェーズのタップは従来どおり捨て札（`card` testid・`data-uid`・座標 E2E 不変）。
- [x] 375px で横スクロールが出ない・横向き 844×390 の縦横 fit が保たれる（プレビュー実マウント相当も検査）。
- [x] 操作ボタンの色分け（おまかせ=金/確定=緑/見送る=ゴースト）の実描画が保たれる。
- [x] `.card--selected` は面の色クラス（`card--pink` 等）と**同時に**付く（面の色を殺さない）。
- [x] 選択リングは hover 下でも残る（詳細度・import 順に負けない）。
- [x] 和了演出中は選択・確定できない（`canSelect` に `pendingWin === null` を含める＝キーボード経路も止める）。
