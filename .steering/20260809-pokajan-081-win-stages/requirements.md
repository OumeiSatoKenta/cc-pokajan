# Step 8-1: 和了演出の作り込み — 要求

## 背景

Step 7-4 で和了が対局を止め、7-5 でカットイン・得点の増減・順位の移動が入った。
その状態でのプレイテストから3点の指摘が出た。

| # | 指摘 | 現状 |
| --- | ---- | ---- |
| 1 | 一度に全部出るので視線が定まらない | 誰が和了したか・何点動いたか・順位がどうなったかが同時に出る |
| 2 | 確認ボタンを毎回押す | 連続宣言は最大8回（`maxChainDeclare`）。最悪8回押す |
| 3 | 大物手が普通の和了と同じ見え方 | 同色役（540〜1800点）も3カード（120点）も演出が同じ |

3 は「和了が見える」ようになったからこそ出た指摘で、7-5 の完了時点では存在しなかった。

## 今回やること

和了演出を**2段**にし、同色役に**大物手バージョン**を入れ、
確認ボタンを**自動クローズ**に置き換える。

```
[0.0s] cutin    アバターがフェードイン + 席名 + 役名
                同色役なら大物手バージョン（金の縁・拡大・きらめき）
[1.2s] result   役の絵札・役名・ボーナス数・獲得点・順位の移動・閉じるボタン
[3.7s] 自動で閉じる → 対局再開
```

## 確認済みの決定

計画時に取得済み（`docs/ideas/pokajan-presentation-and-counts-plan.md`）。

| 項目 | 決定 |
| ---- | ---- |
| 高得点の基準 | **`candidate.sameColor`**（同色役かどうか）。点数の閾値は持たない |
| 段の長さ | カットイン **1.2秒** → 点数獲得結果 **2.5秒** → 自動で閉じる |
| 途中の飛ばし方 | **クリックで1段進む**（カットイン→結果→閉じる）。Escape で即閉じ |

> **帰結**: 5人組（480点）は通常演出、3カード同色（840点）は大物手になる。
> 点数の大小と演出の大小が一致しない場合があることを承知のうえでの選択。

## 受け入れ条件

- [ ] 和了時にカットイン段が先に出て、一定時間後に点数獲得結果段へ進む
- [ ] **確認を押さなくても自動的に閉じ、対局が再開する**
- [ ] 同色役では大物手バージョンのカットインが出る
- [ ] 点数獲得結果に**役の構成カード**（`candidate.cards`）が絵札で出る
- [ ] ボーナスを含む役ではボーナス枚数が出る
- [ ] クリック1回では閉じず、カットイン段から結果段へ進む
- [ ] Escape でいつでも閉じられる
- [ ] **閉じる操作が二重に走っても和了は1件しか消えない**（連続和了の2件目が消えない）
- [ ] 連続和了でカットインが2回とも頭から出る
- [ ] 閉じるまで対局が進まない（山札も自分の河も動かない）
- [ ] アバター未設定でも席名の頭文字で成立する
- [ ] 375px で演出が画面からはみ出さない
- [ ] 「視覚効果を減らす」設定で**動きが消え、段の滞留時間は変わらない**
- [ ] 既存の E2E 67 件が通る
- [ ] 全ファイルが 400 行を超えない

## やらないこと（Step 8-1 の範囲外）

| 項目 | 理由 |
| ---- | ---- |
| 残り枚数の確認 | Step 8-2 |
| 効果音 | 音源をリポジトリに置かない方針（著作権） |
| 演出の長さをプレイヤーが選べる設定 | まず既定値で遊んでもらってから判断する |
| 精算バランス調整 | ユーザーが「あとでします」と保留 |
| カードの質感・卓の背景 | Step 7 から継続の積み残し |
